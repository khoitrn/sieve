The six fields below are the output of the grill. Fill each one. A field is done when a builder with no other context could not go wrong. For a feature on an existing project, context and tools may be pre-filled from the project; goal and verification usually need fresh answers.

## 1. Goal

What does done look like, stated as something checkable. Not "make it good."

## 2. Context

What is known going in. Who this is for. What already exists around it.

## 3. Tools

What can be used or called. What is explicitly off the table.

## 4. Loop

How the work repeats: plan, execute, verify, retry. Where it stops.

## 5. Verification

How success is checked by a process with no context except the output and the criteria. Testable, not judged. List the concrete checks.

## 6. Human checkpoint

Where a person reviews before proceeding. Scoped by risk, not applied uniformly. Name the specific points that need a human yes.

## Open questions

Anything unresolved. An open question is not a blocker unless marked so.

## Decision log

Append one line per decision or pivot, newest last, so the history of the idea is visible.
